# APV-T Bifacial Agrivoltaic-Thermal Simulation Framework

A complete simulation tool for vertical bifacial solar thermal collectors (IGFPC) in agrivoltaic dual-use arrays. Combines view-factor irradiance modeling, ISO 9806 thermal performance, FAO-56 crop shading, and dual-use land economics in one workflow.

**Project:** CETPartnership / InES STRAWBERRIES (Grant ID: 03EN6041A)
**Institution:** Technische Hochschule Ingolstadt, Institute of new Energy Systems (InES)

## Quick Start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Download weather data (see FIRST_RUN.md)
#    Place CSV files in data/

# 3. Run the full pipeline
python src/main.py
```

## What You Get

- Base simulation with hourly results
- 55-parametric sensitivity sweep
- 19 publication-ready figures (300 DPI)
- Literature validation tables
- Multi-site comparison (Germany, Belgium, Sweden)
- Economic analysis (LCOE, NPV)

## Key Results (Ingolstadt, East-facing, 4m spacing)

| Metric | Value |
|--------|-------|
| Bifacial thermal yield | ~243 kWh/m²/yr |
| Bifacial thermal gain | ~84% |
| Crop yield (strawberry) | ~4.7 t/ha |
| LER | ~1.17 |
| LCOE | ~0.17 EUR/kWh |
