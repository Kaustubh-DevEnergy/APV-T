# APV-T Bifacial Agrivoltaic-Thermal Simulation Framework

## Overview

A complete simulation tool for vertical bifacial solar thermal collectors (IGFPC) in agrivoltaic dual-use arrays. Combines view-factor irradiance modeling, ISO 9806 thermal performance, FAO-56 crop shading, and dual-use land economics in one workflow.

## Quick Start

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Download weather data
#    See FIRST_RUN.md for download links

# 3. Run the full pipeline
python src/main.py
```

## Project Structure

```
apvt_project/
├── src/                    # Python source modules
│   ├── main.py            # Entry point — runs everything
│   ├── config.py          # Dataclasses & system definitions
│   ├── irradiance_model.py  # View-factor irradiance engine
│   ├── thermal_model.py   # ISO 9806 IGFPC thermal model
│   ├── crop_model.py      # AquaCrop / empirical crop model
│   ├── economic_model.py  # LCOE, NPV, dual-use land economics
│   ├── simulation.py      # Master simulation orchestrator
│   ├── parametric_study.py # Multi-dimensional sensitivity analysis
│   ├── plotting.py        # Automated figure generation
│   ├── validation.py      # Literature benchmark evaluation
│   ├── utils.py           # PVGIS TMY parser & helpers
│   └── test_*.py          # Test suites
├── data/                   # PVGIS TMY weather CSV files
├── results/                # Output generated by main.py
├── docs/                   # Additional documentation
├── requirements.txt        # Python dependencies
└── README.md              # You are here
```
